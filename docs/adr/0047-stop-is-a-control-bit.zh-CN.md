# 0047 —— 停止是 realm 里的一个控制位，它的入口是一条框架原语

> **语言：** [English](0047-stop-is-a-control-bit.md)（主文档） · [中文](0047-stop-is-a-control-bit.zh-CN.md)

**状态：** 已接受（2026-11-09），并于同日分两级建成。一级（SET，协作那半）：`crates/realm/src/stop.rs`、`Realm::stop_set`/`stop_clear`、`stop.poll`/`stop.clear` 两条臂、驱逐时清位。二级（INTERRUPT）：realm 为每次在跑的调用安一个中断槽、把 body 与它赛跑，调用方拿到 `Interrupted`（ADR-0012 的终局值），Remote 体则用 `Frame::Interrupt` 通知节点——节点那半在 effector，guest 那半在 induction ADR-0003。写明而不掩饰的边界：摸不到工作的载体回 `landed: false`（steel 与 python 是进程内 VM），一次性 exec 载体尚未 arm。
**日期：** 2026-11-09

## 背景

一轮 turn 可能跑几分钟，必须有东西能停下它。两个看起来显然的形状在这里都不成立。

**当成应用事件。** 投递给一个正在干活的实例的事件，会进入该实例的队列，排在活后面。2026-11-09 在 gravity 的 turn 摊位上实测：按 `device` 键的取消只在 turn 结束后才生效，而同一条入口以调用打给同一实例则与它重叠。所以消息到不了一个忙着的激活——这和 gravity ADR-0008 从另一侧得出的结论一致。

**当成存储里的标记。** 行对所有人可见，turn 跑着也能读——但它把取消变成了应用状态，而取消不是。取消是资源控制，与这个 realm 里已有的 watchdog（`max_exec`）同一族：进程不再跑的激活不欠任何东西，turn 做过什么的记录在存储在（行留 OPEN，投影跳过）。为一件随被停的工作一起死掉的事实做持久化，买不到任何东西。

## 裁决

**裁决——每个激活一份内存态，入口一条、两个动作，入口归框架。**

1. **状态是内存不是存储。** 一张按 `(instance, call)` 键的表，放在 watchdog 自己那本账旁边，沿用 realm 已有的按实例控制锁纪律。驱逐时随实例的其余状态一起清掉。没有表、没有 ns、没有恢复路径——没有什么可恢复。
2. **两个动作：置位与中断在途。** 置位是协作式：激活在它本来就有的边界上读到，然后不再发起新工作。中断在途则通过执行层放弃正在跑的操作，只服务置位够不到的那一种——激活卡在 LLM 流、mount 调用或脚本里。
3. **中断以值的形式回来，不是信号。** 调用失败成 INTERRUPTED 错误，按 ADR-0012 的形状越过边界交给 guest，并且是**终局**：处理者不许重试。这是强制停止能活过重试循环的唯一办法。
4. **谁可以要求。** 场馆的 sender 信封说明是谁在要求（一个绑定用户，或者没人）。至于这是不是他的活，由应用判定：gravity 拿标记里的 member 与 turn 自己的比对。realm 不发明它看不见的归属模型（ADR-0018 把身份留在连接侧）。
5. **执行层只给一种原语。** 按载体落地：杀脚本子进程、drop 在途请求，嵌入语言够不到时终止节点进程——watchdog 那一族的粗粒度。它不承担两级；软停止是应用的事。
6. **入口不是摊位事件，也不是对外的 RPC。** 它是对旁路的 realm 调用：要么由本来就握有该连接权限的一方发起（浏览器侧是 prism），要么由 realm 自己发起（watchdog 就是这样用的）。摊位不能要求停另一个实例：需要这个的摊位，缺的是它自己的边界逻辑。

## 已考虑并否决

- **应用 ns 里的一行当标记**（gravity 目前的过渡实现）：它现在能用，今天这条取消正是靠它，但它存的是资源控制，而且需要一个第二实例在第一个跑着的时候来写。随本记录的原语到位而退役。
- **排队的事件**：实测到不了一个忙着的激活。作为机制否决，作为客户端"请求取消"的线上形状保留。
- **把杀进程当协作路径**：那是 watchdog 的轮廓，且会丢掉 turn 写下的每一行。它是中断在途的最后手段，绝不是一次点击的第一答案。

## 后果

- 一张表加一把锁的数据结构；测试可以从激活之外置位、观察处理者在其边界停下，也可以对一个卡住的调用发中断、观察 INTERRUPTED 值。
- realm 多了一项它原本没有的权限：它能中断一个激活。范围故意限定为一个实例、一个调用。
- `max_exec` 与中断在途是通往同一次唤醒的两条退役路径——watchdog 驱逐，中断返回。二者不可合并：一个是预算，一个是意图。
